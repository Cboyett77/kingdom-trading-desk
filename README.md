# ⚜ Kingdom Trading Desk

> **Money first. Command logic underneath. Iron Man x Primeworld.**

The Kingdom Trading Desk is the team's unified command surface for daily trade execution — bias setting, watchlist management, setup grading, and morning briefings all in one place. Built on the Primeworld operating infrastructure.

---

## 🚀 Live Preview

Open `index.html` directly in any browser — no server required. It's a single-file app.

```
git clone https://github.com/Cboyett77/kingdom-trading-desk.git
cd kingdom-trading-desk
open index.html
```

---

## 📊 What's Inside

| Section | Purpose |
|---|---|
| **Morning Brief** | Daily bias + phase tracking for XAUUSD, QQQ, SPY, BTC, ETH, DXY |
| **Kingdom Watchlist** | Live TradingView chart embed with W/D/8H/4H/1H/15M timeframe switcher |
| **Setup Ladder** | A/B/C/D grade tiles per ticker — mark entries in real time |
| **Trade Flow Routine** | 5-step bias-to-journal execution sequence |
| **PWI Daily Checklist** | Insurance brokerage tasks with auto-save progress bar |
| **Sales Pipeline** | AZ stage counts + quick-launch links |
| **KPI Stats Row** | MTD Revenue, Calls, Policies Sold, Quotes Out, Appts Set |
| **Command Trays** | One-click launch tiles for every tool (TradingView, Robinhood, AgencyZoom, Zoho) |
| **Macro Framework** | W/D/4H/1H structure notes for context |
| **Dock + Routines** | Sticky bottom bar with Money Stack, Morning Prep, PWI Flow, Night Reset modals |

## 🛠️ Tech Stack

- **Pure HTML/CSS/JS** — zero dependencies, zero build step
- **TradingView widget** embed for live charting

- **CSS variables** for full light/dark theme support
- **Google Fonts** — Cinzel + Inter

## 👥 Team Contribution Guide

See [CONTRIBUTING.md](./CONTRIBUTING.md) for the full workflow.

### Quick rules:
1. **Branch off `main`** — never commit directly to main for new features
2. Branch naming: `feature/your-feature-name` or `fix/bug-description`
3. Keep `index.html` as the single source of truth
4. Test in browser before opening a PR
5. Add a clear PR description: what changed, why, screenshot if UI change
